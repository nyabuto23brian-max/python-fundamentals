# Python Fundamentals & Data Analytics Practice

A structured repository containing clean, modular Python scripts and practical mini-projects focused on data structures, control flow, and input validation pipelines.

## Repository Structure

- `01_variables_and_types.py`: Variable declaration, type casting, and basic arithmetic operations.
- `02_if_statements.py`: Conditional logic, boolean operators (`and`, `or`, `not`), and ternary expressions.
- `03_string_methods.py`: String cleaning, method chaining (`.replace()`, `.upper()`), and regex-free validation routines.

## Key Skills Demonstrated
- PEP 8 compliant code structure and modular design.
- Input validation and string sanitization pipelines.
- Git version control workflow (commit & push routine).
